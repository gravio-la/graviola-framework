# Semantic chips

Chips are the **smallest read-only entity view** (`viewSize="chip"`). They appear standalone, inside tables, and nested in detail views via `NamedEntityRenderer` → `ContainedSemanticChip`.

## Convention before configuration

- Default: `generateDefaultChipUISchema` → `ChipLayout` with slots from `primaryFields` (label, image, …).
- Override: `viewConfig.chip` on `AdbProvider`, or per-control `options.containedAs: "chip"` in detail UISchema.

## Baseline renderers (detail / semantic-views)

| Tester / layout | Renderer |
| --------------- | -------- |
| `uiTypeIs("ChipLayout")` | `ChipLayoutRenderer` |
| `namedEntityTester` | `NamedEntityRenderer` (embeds chip) |
| Value format options | `pickValueRenderer` (currency, historical date, …) |

Registry: `packages/detail-renderer/src/renderers/registries.ts` (`defaultChipRenderers`).

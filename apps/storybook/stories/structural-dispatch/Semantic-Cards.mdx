# Semantic cards

Cards are the **gallery / search-hit** view size (`viewSize="card"`): hero media, title, and description from `primaryFields`, secondary leaf properties via ranked value renderers, and optional actions — all driven by schema and `cardPresentation` config.

## Convention before configuration

- Default: `generateDefaultCardUISchema` → `CardLayout` (M3 elevated / filled / outlined).
- Per-type knobs: `AdbProvider.cardPresentation` or `viewConfig.card.options`.
- Override: custom `CardLayout` renderer, full card component via `SemanticCardSlotProvider`, or `uiSchemata`.

## Card presentation options

| Option | Purpose |
| ------ | ------- |
| `secondaryFields` | Explicit leaf properties in the card body |
| `secondaryDisplay` | `inline` (value renderers) or `stats` (profile-style strip) |
| `actions` | M3 action row (`show` / `edit` / `custom` intents) |
| `variant` | `elevated` · `filled` · `outlined` |
| `orientation` | `vertical` · `horizontal` |
| `size` | `compact` · `standard` · `comfortable` |
| `expandable` | In-place expand (distinct from detail modal) |
| `mediaOverlay` | Headline over hero image with scrim |
| `banner` | Profile-card banner property (avatar overlaps) |

## Baseline renderers

| Layout | Renderer |
| ------ | -------- |
| `CardLayout` | `CardLayoutRenderer` |
| Nested entities | `NamedEntityRenderer` + `SemanticComponentMap` |

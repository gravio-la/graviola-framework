# Semantic cards

Cards are the **gallery / search-hit** view size (`viewSize="card"`): image, title, description slots from `primaryFields` and optional entity preview.

## Convention before configuration

- Default: `generateDefaultCardUISchema` → `CardLayout`.
- Override: `viewConfig.card` or custom `cardUiSchemata`.

## Baseline renderers

| Layout | Renderer |
| ------ | -------- |
| `CardLayout` | `CardLayoutRenderer` |
| Nested entities | `NamedEntityRenderer` + `SemanticComponentMap` |

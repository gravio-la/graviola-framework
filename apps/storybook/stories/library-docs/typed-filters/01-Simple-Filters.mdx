# Simple Filters

Scalar `where` operators against `City` in the geo fixture.

## Operator cheat sheet

| Schema type | Operators |
| --- | --- |
| string | `equals`, `not`, `in`, `notIn`, `contains`, `startsWith`, `endsWith`, `mode` |
| number / integer | `equals`, `not`, `in`, `notIn`, `lt`, `lte`, `gt`, `gte` |
| boolean | `equals`, `not` |
| logical | `AND`, `OR`, `NOT` (combinators over where objects) |

## All cities (baseline)

## Population threshold

`{ population: { lt: 20000 } }` — verified against Oxigraph even though the Turtle
literals are `xsd:decimal` (filter literals are `xsd:integer`; Oxigraph still
compares them correctly here).

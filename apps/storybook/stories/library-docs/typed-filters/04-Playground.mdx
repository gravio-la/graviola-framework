# Playground

Pick **one** filter source — Controls **or** JSON — never both at once.

- **Controls** — `populationLt` / `nameContains` in the Controls panel drive
  `where`. A read-only JSON preview shows the derived filter.
- **JSON** — edit `where` / `include` / `select` freely. Knob fields for
  population and name are ignored (and hidden). `typeName` and `take` still
  apply.

Switching to JSON seeds the editor from the current Controls values.

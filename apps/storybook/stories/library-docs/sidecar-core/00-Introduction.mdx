# @graviola/sidecar-core

Shared utilities for **scope-keyed companion documents** (Layer 1). Fingerprint
binding, dangling-scope diagnostics, payload-agnostic validation — not a global
document schema.

| Concern | `$schema` | Package |
|---|---|---|
| Calc profile | `calc-profile/v1` | `@graviola/formula-dependency` |
| Meta profile | `meta/v1` | `@graviola/meta-schema` |
| UI / display | app-specific side-schema | JSON Forms + LinkML |

## Calc-profile envelope (uses this package)

```json
{
  "$schema": "https://graviola.gra.one/calc-profile/v1",
  "appliesTo": {
    "schema": "https://myapp/schema",
    "version": "1.2.0",
    "fingerprint": "sha256-…"
  },
  "slots": {
    "#/definitions/Person/properties/fullName": { }
  }
}
```

`fingerprint` is the machine identity; `version` is advisory for humans and diagnostics.

## API

- `createSidecarDocument(documentSchema, appliesTo, slots)` — caller supplies the concern-specific `$schema` IRI
- `validateSidecar(sidecar, expectedIdentity, knownScopes)`
- `formatAppliesToLabel(appliesTo)` — e.g. `https://myapp/schema v1.2.0 (sha256-ab12…)`
